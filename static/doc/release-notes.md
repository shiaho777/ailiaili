## 1.4.0（未发布）

### 播放

- 安卓自适应缓冲：与桌面同一套 BufferPolicy 决策，弱网深预读抗抖动、快线浅预读省内存；直播单独收紧延迟档位。换片时生效，不影响播放中途。
- 播放/暂停中央图标浮现反馈（单击、双击、空格、控制栏按钮统一）；移动端双击左右区 ±10 秒改为侧边胶囊动画反馈。
- 播放器顶栏与控制栏淡入淡出，不再瞬间弹跳。
- 修复长视频片尾最后 1~2 秒无声：LibVLC 统一 `:demux=avformat`，完整读到 fMP4 最后一个分片。
- 修复播完后点进度条黑屏：已结束的媒体改为 `:start-time` 重建定位，重播按钮同路径。
- 清晰度菜单不再列出播不了的档位：桌面剔除杜比视界/HDR/8K；Android 按 MediaCodec 实测解码能力过滤，支持的机型不误杀。偏好不可播档自动降到最高可播档。
- 字幕（CC/AI）全链路：浮层渲染、默认关闭、语言记忆、C 键开关、Z/X ±0.2s 延迟微调；Android 与桌面同一套渲染。

### 下载与直播

- 离线缓存自动合流为单个 MP4：安卓用系统 MediaExtractor+MediaMuxer 无损合流（不重编码、零第三方依赖），可导出到任意播放器；合流失败保留双流回退；合流件正常播放 5 秒后自动清原始双流省一半空间。桌面保留双流（VLC 原生支持外挂音轨）。
- 直播主播卡完善：粉丝数、官方认证文案、页内关注/取关按钮（进直播间自动同步关注状态）。

### 内容

- 评论区独立详情页：点「查看 N 条回复」进楼中楼，完整回复分页、热门/时间页内切换不弹回、页内直接回复；导航栈恢复时自动反查根评论。
- 视频搜索排序：综合 / 最多播放 / 最新发布 / 最多弹幕，切换即重搜。
- 播放器截图：桌面从帧泵取现成帧存 PNG；安卓 PixelCopy 只抓视频表面（不带弹幕/控制栏叠层）存相册；控制栏相机按钮。
- 动态页升级为综合动态：图文（OPUS/专栏/绘画/纯文字/转发）+ 视频统一卡片流；新增动态详情页与完整评论区（热门/时间、楼中楼、发评回复、点赞）。
- 图片预览支持多图左右切换：触屏横滑、桌面箭头与 ←/→ 键；放大态先平移，缩回 1x 才翻页。
- 评论/简介/动态正文自动识别链接：URL 高亮可点走系统浏览器，BV 号直接进应用内播放器。
- 私信支持表情面板与本地图片发送；宽屏双栏微信式布局；收到的表情内联渲染、图片点开预览。
- 自定义界面字体：桌面可选系统字体，双端可导入 ttf/otf；全应用与弹幕跟随，坏字体自动拦截。

### 交互

- 长按点赞一键三连：两段式确认 + 进度环，松手即取消；点赞/投币/收藏逐项独立执行。
- 长按 → 方向键 3 倍速快进，松开恢复；短按仍快进 5 秒。触屏长按画面同步对齐 3 倍速。
- F5 刷新当前列表页（首页/动态/搜索/分区/历史/收藏/稍后再看/消息/空间/番剧）。
- 视频卡悬浮「稍后再看」按钮（桌面悬停显示），移动端长按/右键菜单同入口；列表行右键菜单覆盖全站。
- 设置新增「显示相关视频」开关，关闭后不请求也不展示。

### 性能与体验

- 滚轮平滑重写为临界阻尼两级滤波：S 形起步、无过冲、反向保留动量；嵌套滚动到边界自动放行外层，不再吞滚轮。
- 封面磁盘缓存 256MB 硬上限（LRU 自动淘汰）+ 内存缓存 64MB；启动自动修剪遗留缓存；手动清理同时清运行中句柄。
- 封面加载占位改为微光骨架扫过动画，替代死灰块；仅加载中绘制，完成即零开销，不加布局层。
- 深浅色/主题色切换改为 240ms 纯颜色渐变，零快照零额外内存。
- 去掉最小化到托盘的气泡通知。

### 接口层

- GET 瞬时失败（网络异常/408/429/5xx）指数退避自动重试；业务错误与写操作绝不重试。
- 同 URL 并发请求单飞合并；WBI 密钥并发去重 + 20 小时主动刷新；buvid 就绪零开销。
- 三个网络引擎共享连接池与调度器，同域 TLS 握手复用。
- 低频只读接口短缓存（热搜/排行/章节+字幕轨/截图索引/表情包/字幕体），章节与字幕共用端点合并为一次请求；播放地址、动态、评论等实时接口不缓存。
- 私信设备号进程内稳定，降低风控特征漂移。

### 性能与架构

- 列表屏蔽过滤全面记忆化：滚动等无关重组不再对整页视频逐条重算；关键词分词改派生状态；空间页过滤属性一处计算多处共享。
- 标题清洗加快速路径（无标签/实体直接返回），正则提升为常量；图文动态解析正则不再逐条编译。
- 桌面帧泵行拷贝缓冲复用，非紧凑行距路径不再每帧分配数 MB 数组。
- 图片全面接 B 站 CDN 缩图：卡片/列表行/合集/收藏夹封面、全站头像（视频卡/评论/动态/空间/我的/消息/搜索用户/UP 筛选芯片）、动态九宫格、评论缩略图、直播看板封面、私信图片气泡，均按显示尺寸 2x 取服务端裁好的小图，流量与解码内存降一个量级；点开预览仍加载原图；GIF 与已带参数的 URL 不动。
- 弹幕关键词正则按原文缓存：长视频每 6 分钟追加弹幕段不再重复编译全部正则。
- 字幕轮询暂停降频：位置未变不做二分查找，暂停时 100ms→500ms，长暂停几乎零开销。
- 播放器巨型文件按职责拆分：评论区组件独立成 PlayerComments.kt（纯移动零逻辑改动，逐行比对校验）。
- 记录模块分层、依赖方向、源集约定与关键机制决策。

### 工程

- 新增单测：画质可播性收敛、滚轮滤波收敛/无过冲/反向、链接扫描、图文动态解析、字幕定位、接口重试/单飞/缓存策略。

## 1.3.0

### 播放

- 720P 及以下优先走 durl 合流单流，改善桌面 VLC 拖动进度条跳回开头 / 卡死的问题；1080P 及以上仍走 DASH。
- 新增自动 / 手动网络缓冲策略：自动档按 CDN 实测带宽挑选预读深度，弱网更深、快线更省内存。
- 同一条 CDN 线路短时间内反复卡顿时，后续视频自动加深预读。
- 桌面端新增长视频 seek 看门狗：超时重发 seek，必要时用 `:start-time` 重建 Media。
- 播放中途卡顿会显示「正在缓冲…」，不再对着冻住的画面干等。

### 网络与登录态

- 游客 UA 从 Chrome/126 升到 Chrome/131，修复未登录时打不开视频详情的问题。
- 游客搜索增加风控降级链：签名端点 → 裸端点 → 换 buvid 重试，修复搜索直接提示风控拦截。
- 免登录 1080P 的设备指纹改为进程内固定，避免长驻进程被判定为设备特征不稳定。

### 评论

- 评论支持图片，点击可看大图。
- 评论支持 B 站自定义表情内联显示。
- 评论正文里的 `@昵称` 高亮显示。
- 评论正文支持拖选复制。
- 评论输入框可展开写长评。

### 动态

- 动态页新增「关注直播」看板：关注的主播正在直播时直接列出，点一下进直播间。

### 界面

- 图片预览升级：双指 / 滚轮缩放、拖动平移、双击在 1x / 2x 之间切换。
- 视频卡封面支持长按（移动端）或右键（桌面端）预览大图。

### 工程

- 版本号 1.3.0。
- 新增评论、durl、关注直播、缓冲策略、seek 看门狗、@ 提及等单元测试。
