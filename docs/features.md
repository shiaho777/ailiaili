# 功能状态

本文只记录 ailiaili 自身的功能与已知限制。

## 播放

- 点播：DASH / durl 自动选流，720P 及以下优先单文件流；不可播档位按平台解码能力过滤
- 番剧/影视：PGC 独立取流（ep_id 链路），失败回退 UGC；大会员/付费内容可播
- 连播：列表队列（收藏夹/稍后再看/合集「播放全部」）> 分P > UGC 合集三级自动连播；队列面板跳选
- A-B 循环：两点锚定区间反复播放，进度条区间标记，换片清除
- 字幕：CC / AI 字幕浮层，语言记忆、C 键开关、±0.2s 延迟微调
- 直播：清晰度切换、主播信息面板、滚动弹幕、弹幕聊天列表、自动重连
- 弹幕：颜色、区域、类型过滤、智能屏蔽、半透明胶囊底衬、跟随界面字体、不透明度（30–100%）、同屏上限（10–80 条）
- 操作：长按点赞一键三连、长按 → 3 倍速、F5 刷新列表、卡片悬浮稍后再看
- 弹幕发送：滚动/顶部/底部 + 七色，最长 100 字，发送后本地即时回显
- 直播发言：聊天列表下发言框（最长 30 字），登录后发送并本地回显
- 睡眠定时器：15/30/60/90 分钟或播完当前，到点自动暂停，剩余倒计时可取消
- Android 画中画：播放中按 Home 自动进小窗，小窗内纯画面
- 音质：DASH 多音轨，AAC / 杜比 / Hi-Res 可选
- 进度：本机记录与自动续播、seek 看门狗、缓冲策略（桌面与安卓均自适应）、CDN 卡顿归因
- 反馈：播放/暂停中央浮现、双击 ±10 秒侧边动画、控制栏淡入淡出、封面微光骨架
- 其他：倍速 0.25–4.0x、听视频、章节、赞助片段跳过、截图预览、进度条拖动/悬停时间气泡、视频画面截图保存

## 浏览

- 首页：推荐 / 热门 / 排行榜 / 直播，网页版与 App 端推荐源切换
- 搜索：视频、直播、番剧、用户；视频排序（综合/播放/最新/弹幕）；最近搜索与热搜
- 分区、排行、UP 空间、番剧详情、动态、消息、收藏/历史/稍后再看
- 历史：本地关键词搜索 + 按观看日分组（今天/昨天/日期）
- 评论：热门/时间排序 + 只看 UP 主筛选
- 关注直播看板：直播中 + 未开播灰态展示；开播提醒（运行期轮询，系统通知，可关）
- 动态：综合动态（视频+图文）、动态详情页与评论区、关注直播看板、未读角标、按最近更新排序、已关注 UP 搜索
- 私信：表情面板、本地图片发送、宽屏双栏布局
- 正文链接：URL / BV 号自动识别，站内视频直接打开
- 图片预览：多图左右切换、缩放平移
- 屏蔽：标题/UP 关键词与精确规则，覆盖主要视频列表，支持单独撤销
- 推荐负反馈：推荐卡「不感兴趣」本地移除 + 登录态上报服务端，驯服推荐流

## 桌面端

- 窗口尺寸与位置记忆、窄窗口适配、最小尺寸约束
- 平滑滚轮与 100–500% 速度调节
- 托盘、快捷键、全屏、下载目录选择
- Windows 全局媒体键：播放/暂停/上一曲/下一曲/停止（托盘最小化时仍可控）

## 数据与外观

- 深色/浅色/跟随系统（240ms 颜色渐变过渡）、主题色、自定义界面字体（系统字体/导入 ttf/otf）
- 播放进度、屏蔽规则、动态已读基准、搜索历史、设置原子落盘
- 多账号：最多 8 个账号槽位，我的页一键切换，设备指纹不随账号走
- HTTP 代理：API/图片/下载/直播弹幕统一走代理，热切换无需重启（视频流除外）
- 离线缓存：应用缓存或自定义目录（桌面直接写入；安卓 SAF 选目录后成品自动复制）；安卓自动无损合流为单个 MP4（可导出任意播放器），验证可播后自动清双流省空间；封面缓存 256MB 上限自动淘汰

## 已知限制

- Android 自定义下载目录为「导出」语义：下载/断点/合流在应用缓存完成，成品复制到所选目录；应用内缓存仍占一份空间（可在离线缓存页删除）
- HTTP 代理不作用于视频流本身（Media3/LibVLC 走系统播放器取流）
- 睡眠定时器为页面级：离开播放页即失效，不做全局后台计时
- 全局媒体键仅 Windows；macOS/Linux 需 objc 桥接/D-Bus MPRIS，未做（窗口内快捷键可用）
- 开播提醒只在应用运行期间生效（桌面托盘常驻可覆盖；安卓退后台被杀即停）；不做服务端预约场次
- 收藏夹「播放全部」队列为已加载的第一页（20 条）；稍后再看为全量
- 桌面下载保留 video.m4s / audio.m4s 双流（VLC 原生支持；引入 ffmpeg 合流会显著增重，暂不做）
- 评论区窗口化回收未做（评论已有独立楼中楼详情页）
- 直播粉丝团勋章/等级面板未做（主播资料卡已有粉丝数/认证/关注）
- AI 字幕未登录时服务端通常不下发；私信图片上限 10MB，GIF 按首帧上传
- 桌面托盘菜单为系统原生样式，无法套应用主题（平台限制）
