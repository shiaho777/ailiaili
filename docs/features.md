# 功能状态

本文只记录 ailiaili 自身的功能与已知限制。

## 播放

- 点播：DASH / durl 自动选流，720P 及以下优先单文件流
- 直播：清晰度切换、主播信息面板、滚动弹幕、弹幕聊天列表、自动重连
- 弹幕：颜色、区域、类型过滤、智能屏蔽、半透明胶囊底衬
- 音质：DASH 多音轨，AAC / 杜比 / Hi-Res 可选
- 进度：本机记录与自动续播、seek 看门狗、缓冲策略、CDN 卡顿归因
- 其他：倍速 0.25–4.0x、听视频、章节、赞助片段跳过、截图预览、进度条拖动/悬停时间气泡

## 浏览

- 首页：推荐 / 热门 / 排行榜 / 直播，网页版与 App 端推荐源切换
- 搜索：视频、直播、番剧、用户；最近搜索与热搜
- 分区、排行、UP 空间、番剧详情、动态、消息、收藏/历史/稍后再看
- 动态：关注直播看板、未读角标、按最近更新排序、已关注 UP 搜索
- 屏蔽：标题/UP 关键词与精确规则，覆盖主要视频列表，支持单独撤销

## 桌面端

- 窗口尺寸与位置记忆、窄窗口适配、最小尺寸约束
- 平滑滚轮与 100–500% 速度调节
- 托盘、快捷键、全屏、下载目录选择

## 数据与外观

- 深色/浅色/跟随系统、主题色
- 播放进度、屏蔽规则、动态已读基准、搜索历史、设置原子落盘
- 离线缓存：应用缓存或桌面端自定义目录

## 已知限制

- Android 下载目录固定为应用缓存
- 下载文件保存为 video.m4s / audio.m4s，暂未合流为单个 MP4
- 评论为内联展开，没有独立详情页与窗口化回收
- 直播暂未提供完整的用户资料/粉丝团面板
