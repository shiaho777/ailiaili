# 上游对齐记录（BiliDesk）

对标仓库：https://github.com/ABING1111/BiliDesk （截至 v1.7.5，2026-11-16）

不照搬 WPF 实现。原则：**功能不缺席，机制取更优解，平台差异诚实标注。**

## 字幕（v1.7.3）

- CC/AI 字幕全链路：`subtitles()` 拉轨列表 → `subtitleCues()` 拉 JSON 字幕体 → Compose 浮层按播放钟二分渲染。
- **超越**：不依赖 VLC/Media3 字幕管线，Android 与桌面同一套渲染与样式；上游仅 Windows。
- 默认关闭、语言偏好记忆（`subtitleLan`）、快捷键 C 开关、Z/X ±0.2s 延迟微调（±5s 夹取）、菜单重置延迟。
- 控制栏显示时字幕自动上移，不被工具条压住。

## 交互效率（v1.7.3）

- **一键三连**：长按点赞两段式（系统长按识别确认意图 → 650ms 进度环扫满触发），松手即取消；
  点赞→投币(2枚)→收藏(默认收藏夹)逐项独立执行，失败不拖累其他项；三按钮激活弹跳已有（`BiliActionItem`）。
- **长按 → 3 倍速**：按住 450ms 进入 3x，松开恢复原倍速；短按仍快进 5 秒。触屏长按画面同步对齐 3x（原为 2x）。
- **F5 刷新**：外壳统一按键 → `PageRefresh` 信号，页面在组合内才注册（tab 缓存页不抢刷新，播放器盖顶时列表不响应）；
  覆盖首页/动态/搜索/分区/历史/收藏/稍后再看/消息/聊天/空间/番剧。
- **稍后再看悬浮按钮**：桌面封面右上角悬停出现，点击即加、会话内选中态；移动端走长按/右键菜单（触屏无悬停）。
  列表行右键菜单同入口。**超越**：全站 VideoCard/VideoListRow 统一接线，不只热门/排行。
- **显示相关视频开关**：设置新增，关闭后不请求也不渲染。

## 主动差异化（不跟上游）

- **弹幕关键词黑名单保留**（上游 v1.6.3 移除）：本项目支持正则且与智能屏蔽叠加，维护成本由用户自选。
- **免登录 1080P / 游客风控降级链**：上游无此能力，保留并持续维护。
- **跨平台**：同一套代码覆盖 Android/Windows/macOS/Linux；上游仅 Windows。

## 接口层优化（自主优化，非对齐项）

不改变任何接口协议与业务语义，只优化请求机制：

| 优化 | 机制 | 收益 |
|---|---|---|
| 传输层重试 | GET 瞬时失败（网络异常/408/429/5xx）指数退避重试 2 次（300→900ms ±20% 抖动）；JSON 业务响应不重试；POST 一律不重试（点赞/投币不可幂等） | 弱网下列表/详情成功率提升，不放大风控 |
| GET 单飞合并 | 同 URL 并发请求共享一次真实网络调用；首个调用者取消/失败时等待者各自回退 | 快速切页/双栏同开不再重复打接口 |
| WBI 密钥治理 | 并发获取单飞（首个请求不再触发 N 次 nav）；20 小时主动过期（B 站按天轮换），长驻托盘进程不等 -403 才发现密钥失效 | 少一次失败往返，签名请求更快 |
| buvid 去重 | 已就绪零开销返回（不进 IO/锁）；未就绪时并发单飞 | 冷启动并发页面只打一次 finger/spi |
| 连接复用 | 三个 OkHttp 引擎共享连接池（12 空闲/5 分钟）与调度器（48 并发/单 host 12） | 同 host TLS 握手复用，图片与 API 不再各建池 |
| 只读短缓存 | 客户端内置 TTL 缓存：热搜 5min、排行/分区排行 10min、player/v2（章节+字幕轨共用端点）10min、截图索引 10min、表情包 1h、字幕体 30min；缓存键含登录态、不含签名时间戳 | 章节与字幕两次调用合并为一次网络请求；返回再进入零请求。**播放地址/动态/评论/私信/搜索等实时接口绝不缓存** |
| 数据层缓存单飞 | TtlCache 同 key 并发未命中合并成一次 load | 详情/空间页双栏同开不重复请求 |
| 私信设备号稳定 | dev_id 进程内固定（原每条消息随机） | 与免登录指纹同一风控原则，降低设备特征漂移 |

单测覆盖：重试判定边界、退避抖动区间、单飞并发合并与失败回退、短缓存过期与容量淘汰。

## 自主功能补强（非对齐项）

- **离线缓存合流 MP4**：安卓系统 MediaExtractor+MediaMuxer 无损合流，零第三方依赖、不重编码；
  合流失败保留双流回退，合流件正常播放 5 秒后才清原始双流（省一半空间且永不丢内容）。
  上游与多数第三方客户端只存双流——这是超越项。桌面保留双流（轻量原则，不引入 ffmpeg）。
- **直播主播卡**：粉丝数（relation/stat）、官方认证、页内关注/取关；进直播间自动同步关注状态。
- **CDN 缩图**：`cdnThumb` 按显示尺寸 2x 生成 hdslb `@{w}w_{h}h` 后缀，全覆盖：
  卡片/列表行/合集/收藏夹封面、全站头像（视频卡/评论/动态/空间/我的/消息/搜索用户/UP 芯片）、
  动态九宫格、评论缩略图、直播看板封面、私信图片气泡；预览对话框仍原图；
  GIF/已带参数/外域 URL 原样保留。尺寸按 10px 取整提高 CDN 边缘缓存命中。
  单测覆盖后缀/取整/查询串/豁免规则。
- **弹幕正则缓存**：关键词规则按原文缓存，分段追加不重复编译。
- **字幕轮询降频**：位置未变跳过二分；暂停 500ms、播放 100ms。

## 已知限制（本轮新增功能的诚实边界）

- AI 字幕未登录时接口通常不下发，属 B 站服务端限制。
- 图文动态点赞走 `dyn/thumb` 聚合接口，个别动态类型可能返回失败（UI 会回滚并提示）。
- 私信图片上传上限 10MB；GIF 按静态首帧上传（B 站接口限制）。
- 系统字体列举桌面端最多 400 个文件（ttf/otf），ttc 集合字体暂不支持导入。
- 一键三连投币固定 2 枚（与 B 站官方长按行为一致），不弹选币窗。
